    The local workbench runs a pinned Llama model on your own computer and can explain one frozen synthetic record through a read-only inspector tool. Its text may be wrong or withheld, and it cannot execute workers, approve actions or verify stored copies. It needs a local install and separately licensed model weights; this hosted page has no interactive model or generated answers.
